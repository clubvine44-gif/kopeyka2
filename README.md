# Копейка 2

Личный финансовый планировщик для сменного графика.

## Архитектура
Один файл `index.html` (HTML + CSS + JS), `cloud.js` — облачная синхронизация через Supabase.
Без сборки, без бандлеров, без загрузки частями.

## Возможности
- Главная: «можно потратить сегодня», касса, резервы+долги
- Календарь смен с расчётом
- Доходы / расходы / резервы / долги
- Меню через плюс (полукруг)
- Голосовой ввод
- Бэкап JSON
- PWA

Данные: localStorage + облако (Supabase).
